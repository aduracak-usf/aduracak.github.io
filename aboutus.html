About the project

Designed to make
planning feel possible.

Roomwise is a student-built interface exploring how everyday design data can help people make informed choices about their homes.

Student developer

Hi, I’m aduracak.

I’m a student learning how web interfaces help people work with information. I built Roomwise for an assignment about interior design, using a room-planning concept to connect design inspiration, furniture-order data, and project organization.

The project helped me practice structuring pages with HTML, creating a consistent responsive system in CSS, and adding browser-side interactions with JavaScript. The room plan manager demonstrates create, read, update, and delete actions with demo plans saved locally in the browser.

The insights page uses Chart.js to visualize summary values calculated from a public furniture orders dataset. This static class project does not connect to a server or provide professional design or cost advice.
