About the project

Designed to make
planning feel possible.

Roomwise is a student-built interface exploring how everyday design data can help people make informed choices about their homes.

Student developer

Hi, I’m aduracak.

In my professional role, I work as a Business Systems Analyst, connecting business needs, processes, and technology. Over the past year, I’ve expanded my development skills by using MCP-enabled tools in my IDE to complete workflows related to my role, and by creating HTML files for ad hoc reports.

For a focused, static report, a lightweight HTML page can be quicker to shape than building a full Power BI dashboard that may take hours to perfect. I’ve also explored data-visualization tools such as Streamlit, working with Python, CSS, and JavaScript. AI often serves as a kickstarter for my work projects; this assignment gave me a chance to apply that approach to building a complete website for the first time.

I’m using Roomwise to learn how web interfaces help people work with information. For this interior-design assignment, I connected room inspiration and a plan manager to furniture-order data, so a user can compare items and estimate a room plan.

This is an AI-assisted project. I began with a prompt for an interactive, visual, data-driven interior-design website about organizing furniture orders by room, including CRUD features and charts. I used AI to help turn that idea into HTML page structure, CSS styling, JavaScript interactions, and D3 data visualizations. I guided the direction, reviewed the results, and refined the site and its content as I learned.

I also checked the dataset before describing it. The Kaggle source is synthetic furniture-order data; it was not collected by Roomwise. This student prototype is not a certified purchaser or distributor of the dataset and has no affiliation with its creator. Its charts summarize the source records, while the room plans are separate demo entries saved in this browser.

The site uses HTML, CSS, JavaScript, D3.js, and GitHub Pages. The static interface does not provide professional design or cost advice.
