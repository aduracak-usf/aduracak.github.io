# Baker's Haven

A responsive bakery website featuring artisan breads, pastries, cakes, baking classes, customer testimonials, and contact information.

## Files

- `index.html` contains the page content and structure.
- `styles.css` controls the layout, colors, typography, and responsive styles.
- `script.js` handles the mobile navigation and current year in the footer.

## Preview locally

Open `index.html` in a browser, or serve this directory with a local web server.
